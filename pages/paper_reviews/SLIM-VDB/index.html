Introduction

로봇은 정확한 월드 맵이 필요함

월드 맵?

  • geometry와 semantics 정보를 포함

    → 로봇이 장면 이해(scene understanding) 및 복잡한 업무 수행을 가능하게 함

  • TSDF (Truncated Signed Distance Function)
    • 환경의 접촉 표면을 표현하여 사실적인 dense reconstruction을 수행

      → 하지만 메모리 요구사항이 크고, 실시간으로 돌리기 어려움..

non-probabilistic semantic mapping

  • semantic segmentation에서 출력되는 semantic label의 불일치(inconsistency)나 깜빡거림(flickering)에 약함

semantics

  • closed-set: 사전에 정의된 클래스 내에서만 예측 수행
  • open-set: 시스템이 알지 못하는 새로운 클래스에 대해서도 예측 수행

→ closed-set만으로도 간단한 세상 이해(world understanding)는 가능

하지만, open-language representation의 사용이 점점 증가

→ closed-set과 open-set 둘다 다룰 수 있는 공식 mapping 프레임워크가 필요함!

OpenVDB

  • 컴퓨터 그래픽스 커뮤니티에서 개발됨
  • 효율적인 volumetric 데이터 저장 가능

VDBFusion

  • OpenVDB를 로봇 매핑 툴로 활용한 사례

    → 연산 속도나 매핑 중 메모리 소모에 있어서 sota급 성능을 보여줌

    → 또한 높은 기하학적 정확도를 유지함

    → 하지만 semantic 매핑 능력이 부족…

이전 연구들

METHODOLOGY

Semantic 매핑

  1. 로봇에 부착된 RGB-D 카메라를 이용한 이미지 수집
  1. Depth 이미지(depth camera, Lidar)를 이용하여 3차원으로 투영
  1. semantic pointcloud 완성

핵심

  • semantic pointcloud의 기하학적 정보

    → TSDF 맵을 업데이트 하는데에 사용

  • global semantic information

    → closed & open-set semantics에서 Bayesian inference을 이용하여 업데이트

  • semantic TSDF 시각화(렌더링)

Surface Reconstruction

Semantic Mapping Pipeline

  • OpenVDB 라이브러리를 이용하여 장면의 기하학적 정보를 voxel로 저장
    • OpenVDB
      • 빠르고, 메모리 효율적인 저장 가능
      • sparse하고 계층적인 데이터 구조를 통한 질문(querying)가능
        • 표면에 근접한 signed distance, weight, and semantic parameters of voxels를 저장

Sensor Processing

  • 각 프레임마다 semantic segmentation된 이미지가 depth image를 통해 3차원으로 투영
    • 투영된 pointcloud는 순차적으로 voxel map을 업데이트

RayCasting

  • 새로운 pointcloud → truncated signed distance 및 voxel 가중치 값 업데이트

Unified Bayesian Semantic Fusion

통합된 closed & open-set semantic fusion

  • closed-form conjugate pair recursive Bayesian update

    → 각 voxel에서 semantic class 추정

  • conjugacy

    → 사전 분포(prior distribution)와 우도 함수(likelihood function)가 주어졌을 때, 사후 분포가 사전 분포와 같은 분포족(faimily)에 남아 있도록 만드는 분포의 조합을 의미

    → 이를 이용하면 새로운 측정값 정보를 반영하기 위해 사전확률의 하이퍼 파라미터만 바꾸면 됌

    → 사후확률에 대한 다루기 쉬운(tractable) 해결책이 됌

  • closed & open-set의 우도 분포가 다름 = 다른 conjugacy
    • closed-set
      • Dirichlet-Categorical conjugacy
    • open-set
      • Normal Inverse Gamma-Normal conjugacy

느낀점

OpenVDB라는 데이터 구조를 이용하여 메모리 효율성과 연산 효율성을 둘 다 잡은 훌륭한 연구였다고 생각한다.

중간에 베이지안 추론 관련해서는 따로 지식이 없어서, 수식을 이해하는데 어려움이 있었지만, 시간을 내서 이해하려고 한다면 충분히 좋은 인사이트를 얻을 수 있지 않을까 싶다.

향후 계획

논문에서 마지막에 모바일 로봇 관련해서 4GB GPU에서 실시간 동작이 가능했다고 하여, 비슷한 세팅으로 데스크톱 환경에서 실습을 해보려구 한다.

→ 환경 문제때문에 진행이 어려울 것 같다… (OpenVDB 버전 문제?)

또한 voxel이라는 개념이 생소해서, pointcloud와 무엇이 다른 것이고, 왜 사용하는지, OpenVDB는 왜 이렇게 효율적인 결과를 이끌어 낼 수 있었는지 등을 찾아볼 것 같다.
