논문 스터디

VGGT

Abstract

우리는 이러한 연구를 했어요

VGGT

  • feed-forward neural network
    • 하나에서 수백 개에 이르는 입력 시점들로부터 모든 핵심 3차원 요소들을 직접 추론함
      • camera parameters
      • point maps
      • depth maps
      • 3D point tracks

기존에는 이러한 문제가 있었어요

보통 모델은 단일 task에 제한되어 있음

→ VGGT는 여러 task에 적용 가능하며, 이는 3D computer vision 분야의 한 발자국을 내딛어줌

따라서 이러한 성과를 가져요

입력 이미지들로부터 1초 이내에 3D 장면을 복원하며, 구조가 단순하고 계산 효율이 좋음

+ 또한 visual geometry 최적화 기법으로 후처리가 필요한 접근법들을 능가하는 성능을 보임

다수의 3D task들에 대해 SOTA급 성능을 보임

  • camera parameter estimation
  • multi-view depth estimation
  • dense point cloud reconstruction
  • 3D point tracking

pretrained VGGT를 feature backbone으로 사용

→ downstream task 성능 향상

  • non-rigid point tracking
  • feed-forward novel view synthsis

Introduction

본 연구는 이렇게 접근돼요

목표

  • 하나의 feed-forward 신경망으로 장면의 3D 속성을 추정

기존 접근법

  • 전통적으로 3D reconstruction 분야는 visual-geometry 방법들로 접근되어 왔음

    → BA(Bundle Adjustment) 같은 반복 최적화 기법 활용

ML의 등장

  • ML(Machine Learning)은 geometry 만으로는 풀 수 없는 task들을 보완해줌
    • feature matching, monocular depth prediction
  • ML과 geometry 통합이 점점 더 긴밀해짐
    • 현재 SOTA급 SFM 방법론인 VGGSFM

      → ML과 visual geometry를 differential BA로 결합

결과

  • 그래도 여전히 visual geometry는 3D reconstruction에서 중요한 역할을 함

    → 복잡도와 연산 비용을 증가시킴

이러한 궁금증이 있었어요

의문점

  • 신경망이 점점 더 강력해지면서, 3D task들이 기하학적 후처리를 거의 완전히 배제한체 신경망에 의해 직접 해결될 수 있는가?

관련 최근 연구들

  • DUSt3R, MASt3R와 같은 최신 연구에서 해당 방향성으로 유망한 결과를 보임

    →하지만, 이들은 함 두 이미지씩만 처리 가능하며, 다중 이미지 재구성을 위해서는 pairwise 결과를 후처리로 융합해야 함

따라서 이런 방법을 제안해요

VGGT

  • 후처리로 3D geometry를 최적화할 필요 없음

결과

  • 추가 처리 과정 없이 기존 최적화 기반 방법론들을 능가하는 성능을 보임

    → DUSt3R, MASt3R, VGGSfM은 후처리 최적화를 거쳐야 쓸만한 성능을 가졌으며, 이러한 후처리 과정은 매우 비용이 컸음

모델

  • 3D reconstruction을 위한 특화된 네트워크를 구성하지 않음
    • 꽤나 일반적인 대형 transformer를 대규모 3D annotation이 달린 데이터로 학습시켜 사용

      → 3D에 특화된 inductive bias가 없음

  • VGGT는 자연어 처리나 컴퓨터 비전 분야를 위한 대규모 모델과 동일한 틀(mold)을 가짐
    • GPTs, CLIP, DINO, Stable Diffusion

      → 새로운, 특정 task들을 풀기 위해 파인튜닝될 수 있는 다용도 backbone으로 만들어진 모델들

대규모 3D 신경망

  • Depth Anything, MoGe, LRM

    → 단일 3D task에만 한정됌 (monocular depth estimaton, novel view synthesis)

  • VGGT
    • 학습
      • 공유되는 backbone을 사용해, 모든 3D 분야들에 대한 예측을 함께 진행

        → 이렇게 상호 관련된(interrelated) 3D 속성들을 예측하는 학습 방법은 잠재적인 중복성에도 불구하고, 전반적인 정확도를 향상시킴

    • 추론
      • 따로 예측되는 depth와 camera parameter를 가지고 point map을 구함

        → dedicated point map head를 이용하는 방법 대비 더 개선된 정확도를 보임

Order of Predictions

  • 입력 시퀀스를 구성하는 이미지의 순서는 첫 번째 이미지를 제외하고, 전부 무작위로 구성됨
  • 네트워크 구조는 permutation equivariant 함 (첫 번째 이미지 제외)

    → 입력의 순서가 그대로 출력의 순서에 영향을 줌

Over-complete Predictions.

  • VGGT의 모든 예측 결과가 항상 독립적인 것은 아님
    • 예를들어 DUSt3R에서 camera parameter g\bold{g}g﻿는 PnP\text{PnP}PnP﻿ 문제를 해결함으로써 invariant point map PPP﻿로부터 예측될 수 있음
    • 게다가 depth map은 point map과 camera parameter로 추론될 수 있음

  • VGGT가 학습 과정에서 앞서 언급한 모든 3D 요소들을 명시적으로 예측하도록 하는 것은 상당한 성능 향상을 가져옴

    → 해당 요소들이 서로 closed-form 관계로 연결되어 있음에도 불구하고 관찰된 결과

  • 추론 단계에서는 독립적으로 추정된 depth map과 camera parameter를 결합하여 3D point를 계산하는 것이, 전용 point map branch를 직접 사용하는 것보다 더 높은 정확도를 보임

Feature Backbone

이미지 - 토큰

  • 모든 프레임에서 추출된 이미지 토큰들의 결합 집합 tI=∪i=1N{tiI}t^I=\cup_{i=1}^N\{t_i^{I}\}tI=∪i=1N​{tiI​}﻿는 이후 메인 네트워크 구조를 통해 처리되며, 이 과정에서 frame-wise self-attention과 global self-attention 레이어가 번갈아 적용됌

Alternating-Attention

  • 표준 Transformer 구조를 약간 수정
    • Alternating-Attention(AA)을 도입

      → Transformer가 각 프레임 내부와 전역 범위에 대해 번갈아 가며 attention함

      • frame-wise self-attention
        • 각 프레임별로 토큰 tkIt_k^ItkI​﻿에 attention을 수행
      • global self-attention
        • 모든 프레임들에 대해, 동시에 토큰 tIt^ItI﻿에 attention을 수행

    → 서로 다른 이미지들간의 정보 통합과 각 이미지 내의 토큰들의 activation 정규화 사이의 균형을 이룸

  • 초기 모델 구조
    • L=24L=24L=24﻿
    • frame-wise attention

  • 중요한 점
    • cross-attention layers는 사용 안함

      → self-attention layers만 활용

Coordinate Frame (좌표계)

위에서 정의한대로, 첫 번째 카메라 g1\bold{g}_1g1​﻿의 좌표계에서 camera, point map, depth map을 예측

첫 번째 카메라의 extrinsic parameter는 identity matrix로 설정

다시 말하지만, 특별한 camera 및 register 토큰인 t1g:=tˉg, tˉ1R:=tˉR\text{t}_1^{\bold{g}}:=\bar{\text{t}}^\bold{g},\ \bar{\text{t}}^R_1:=\bar{\text{t}}^Rt1g​:=tˉg, tˉ1R​:=tˉR﻿는 transformer가 첫 번째 카메라를 인식하게 함

Ground Truth Coordinate Normalization

문제점

  • 장면의 크기 변경 및 global reference frame의 변경은 장면 이미지에 영향을 주지 않음

    → 위 요소들이 변경돼도 3D reconstruction 결과는 모두 유효함

    → 결과가 바뀐다 해도 3D reconstruction의 기준 좌표계가 바뀌거나, 비율만 바꿔서 출력됌

해결

  • 이러한 모호성을 데이터 정규화로 해결하며, 표준적인(canonical) 선택을 하게끔 함

과정

  1. 모든 3D quantity를 첫 번째 카메라 g1\bold{g}_1g1​﻿의 좌표계 기준으로 설정
  1. point map PPP﻿에 있는 모든 점과 원점 사이의 평균 유클리디안 거리 계산
  1. 해당 평균 거리를 scale로 사용하여 아래 요소들을 정규화
    • camera translation t\bold{t}t﻿
    • point map PPP﻿
    • depth map DDD﻿

(참고로 transformer의 출력에는 해당 정규화를 적용하지 않으며, 대신에 모델이 해당 canonical normalization을 학습하도록 함)

Experiments

Camera Pose Estimation

사용한 데이터셋

  • CO3Dv2

    → 학습용

  • RealEstate10K

    → 추론용

평가 지표

  • AUC@30
    • RRA(Relative Rotation Accuracy) + RTA(Relative Translation Accuracy)

      → 각각 이미지 쌍의 회전과 이동에 대한 relative angular error를 계산

      • relative angular error는 accuracy scores를 결정하는 임곗값으로 사용
    • AUC는 각 threshold(x축)에 따른 RRA와 RTA의 curve(y축) 면적중에 작은 값을 사용

      → 회전과 이동 중 더 안좋은 성능을 기준으로 평가

결과

  • 연산 비용이 큰 post-optimization 과정을 거치는 방법들을 능가하는 성능을 보임
    • Global Alignment - DUSt3R/MASt3R
    • Bundle Adjustment - VGGSfM

      → 위 방법들은 실행 시간이 10초 이상 소요됨

      → 반면, VGGT는 동일 하드웨어에서 단 0.2초만 소요

  • 또한 모델 학습에 사용하지 않은 RealEstate10K에서 다른 방법론들 대비 가장 좋은 성능을 보임

    → VGGT의 탁월한 일반화 능력을 검증

추가적인 성능 개선

  • BA와 같은 visual geometry optimization을 결합하여 더욱 성능을 향상 시킬 수 있음

    → 특히 예측된 camera pose와 track을 BA로 보완하면 정확도가 향상됨

  • VGGT는 거의 정확한 point/depth map을 직접 예측

    → BA에 좋은 초깃값을 제공

    → BA에서 triangulation이나 iterative refinement 과정이 필요없어짐

    • 실행 시간
      • BA를 포함해도 대략 2초 소요 (매우 빠름)

  • 결론
    • VGGT가 feed-forward mode로 모든 이전 방법론들을 능가하는 성능을 보이지만,

      pose-optimization이 가져오는 성능 향상의 여지는 여전히 존재

Multi-view Depth Estimation

MASt3R와 비슷하게 DTU 데이터셋을 이용하여 multi-view depth estimation 결과를 제공

DTU 평가 지표

  • Accuracy
    • 예측 포인트에서 GT 포인트까지의 최근접 거리의 평균
  • Completeness
    • GT 포인트에서 예측 포인트까지의 최근접 거리의 평균
  • Overall
    • Accuracy와 Completeness의 평균 (Chamfer distance)

방법론

  • DUSt3R, VGGT

    → GT 카메라 없이 동작

  • MASt3R

    → GT 카메라를 사용해 매칭된 점들을 triangulation하여 depth map을 생성

  • GeoMVS-Net같은 deep multi-view stereo 방법들

    → cost volume을 만들기 위해 GT 카메라를 사용

결과

  • VGGT
    • DUSt3R을 능가
      • 1.741 → 0.382
    • 테스트 시에 GT 카메라를 사용하는 방법론들과 유사한 성능 달성
    • 성능 향상의 원인
      • 다중 이미지 학습 방식이 모델이 multi view triangulation을 내재적으로 추론하도록 하며, 이는 DUSt3R와 같이 다수의 카메라 쌍으로 triangulation을 진행한 것의 평균으로 정렬하는 임시 방편의 과정에 의존하는 것 보다 더 좋은 성능을 낸다.
      • 다중 이미지 기반 학습을 통해, 모델이 multi-view triangulation을 내재적으로 추론하도록 학습됨
      • DUSt3R처럼 여러 쌍의 카메라에 대해 개별 triangulation을 수행한 뒤, 이를 평균 정렬하는 ad hoc alignment 절차에 의존하지 않음

        → 그 결과, 보다 일관되고 정합성 높은 depth 추정 가능

Point Map Estimation

DUSt3R과 MASt3R에 대해 ETH3D 데이터셋을 이용하여 예측한 point cloud의 정확도를 비교

각 scene에서 임의로 10개 프레임을 샘플링

예측된 point cloud는 Umeyama 알고리즘을 이용해 GT point cloud에 정렬

평가 지표

  • Accuracy, Completeness, Overall

결과

  • DUSt3R, MASt3R
    • 높은 비용의 최적화 기법을 수행
    • 한 장면마다 대략 10초정도 소요
  • VGGT
    • 전반적인 지표에서 DUSt3R, MASt3R을 능가
      • 한 장면마다 대략 0.2초 소요
      • 더 높은 정확도

반면에 point map을 직접적으로 예측하는 것보다, 예측된 depth와 camera heads를 이용한 역투영(unprojection)으로 구한 3D point가 더 높은 정확도를 보임

→ 이는 camera, depth map, point map이 동시에 supervised 되고 있음에도 불구하고, 복잡한 task를 간단한 하위 task들로 분해하는 것에 대한 이점을 보임

위는 VGGT의 정성적 비교 결과를 보여주며, 유화(oil painting), 겹치는 부분이 없는 프레임 쌍, 사막(desert)처럼 균일한 질감을 가진 장면들과 같이 다루기 어려운 이미지들에 대해서도 뛰어난 결과를 보임

Image Matching

Two-view image matching은 rigid point tracking의 특수한 경우(두 시점으로 제한된 경우)로 볼 수 있음

→ VGGT는 해당 task에 특화된 모델은 아니지만, tracking 정확도를 평가하기 위한 적절한 벤치마크로 사용

사용한 데이터셋

  • ScanNet

평가 과정

  1. 각 이미지 쌍에서 매칭점을 추출
  1. 매칭점을 이용해 essential matrix 추정
  1. essential matrix를 상대 카메라 포즈로 분해
  1. 상대 포즈 오차에 대한 AUC를 최종 지표로 사용

구체적인 환경

  1. ALIKED를 이용하여 keypoints 검출

    → query points yq\bold{y}_qyq​﻿로 사용

  1. tracking branch T\mathcal{T}T﻿를 통해, 두 번째 프레임에서 yq\bold{y}_qyq​﻿에 대응하는 2D point 예측
  1. 매칭 개수, RANSAC threshold 등의 하이퍼파라미터는 RoMa 설정을 따름

결과

  • VGGT는 image matching에 특화되어 학습되지 않았음에도 불구하고, 모든 baseline 대비 가장 높은 상대 포즈 정확도(AUC)를 달성

Ablation Studies

Feature Backbone

제안한 AA(Alternating-Attention) 구조의 효과를 검증하기 위해 변형 구조들과의 비교를 진행함

변형 구조

  1. global self-attention only
  1. cross-attention

조건

  • 공평한 비교를 위해 모든 모델 구조는 2L2L2L﻿개의 Attention Layer 및 동일한 파라미터 수를 가짐
  • hidden dimension, head의 수 등의 하이퍼 파라미터는 모두 동일

특징

  • cross-attention
    • 각 프레임의 토큰이 다른 모든 프레임들의 토큰에 대해 attention 연산을 독립적으로 수행

      → cross-frame information fusion을 최대화하지만, 입력 프레임에 비례하여 실행시간 증가

평가 방법

  • Point map estimation accuracy

    → scene geometry와 camera parameters에 대한 모델의 이해도를 평가하기에 적합

결과

AA 구조를 사용한 모델이 다른 두 변형 모델들 대비 명확한 차이로 능가하는 성능을 보여주었으며, Cross-Attention을 사용한 모델은 Self-Attention만 사용한 구조보다도 못한 성능을 보였다.

Multi-task Learning

일부 출력이 서로 중복될 수 있음에도 불구하고, 단일 네트워크가 동시에 다수의 3D quantities를 학습하는 것에 대한 이점을 검증함

(예를들어 depth map과 camera parameter를 이용하여 point map을 추정할 수 있음)

결과

  • 각 3D quantity를 제외하고 학습할 경우, point map 정확도가 눈에 띄게 감소
  • 특히, camera parameter estimation을 포함시키는 것이 point map 정확도를 크게 향상
  • 반면, depth estimation은 point map accuracy 향상에 상대적으로 작은 기여를 보임

과정

  • LVSM의 training, evaluation protocol 적용
    • 예를들어 4개의 입력 시점 및 Plucker ray를 사용하여 target view를 나타냄
  • VGGT 수정
    • 이전: DINO로 입력 이미지 토큰화
    • 이후: convolution layer로 Plucker ray 이미지들을 토큰화

      → 만들어진 토큰들은 입력 이미지와 target view를 나타냄

  • 그 후, DPT head는 target view의 RGB 색상을 예측하는데 사용
  • 추론(source) 이미지에는 Plucker ray를 넣지 않음 (따라서 해당 이미지들의 camera parameter도 주어지지 않음)

데이터셋

  • LVSM
    • Objaverse dataset 사용
  • VGGT
    • Objaverse dataset과 비슷한, 1/5 크기의 데이터셋 사용

평가

  • 데이터셋
    • GSO dataset

  • 정량적 평가

    VGGT는 입력 이미지에 대한 camera parameter가 주어지지 않았고, LVSM 보다 훨씬 적은 데이터로 학습되었음에도 불구하고, LVSM에 버금가는 성능을 보여주었다.

    (훈련 데이터 크기가 더 컸으면 더 좋은 결과를 보여줬을 듯 하다)

  • 정성적 평가

Dynamic Point Tracking

평가 지표

  • Occlusion Accuracy (OA)
    • 가려짐(occlusion) 예측의 이진 정확도
  • δavgvis\delta_{\text{avg}}^{\text{vis}}δavgvis​﻿
    • 보이는 점들 중, 예측 위치가 GT와 특정 threshold 이내에 있는 비율의 평균
  • Average Jaccard
    • tracking 및 가려짐 예측 정확도를 같이 측정

구조

  • CoTracker2
    • backbone을 VGGT로 수정
      • VGGT: unordered image로 학습됨
      • CoTracker2: sequential video 기반 모델

        → VGGT를 tracking 모델로 그대로 쓰는 것이 아니라 feature extractor 역할만 하도록 backbone만 교체

  • Kubric dataset으로 fine tuning

평가 결과

  • TAP-Vid benchmark
    • VGGT backbone으로 CoTracker의 성능을 개선
    • TAP-Vid RGB-S
      • VGGT backbone에서 추출한 tracking feature는 δavgvis\delta_{\text{avg}}^{\text{vis}}δavgvis​﻿를 78.9 → 84.0 으로 개선

TAP-Vid benchmark

  • 다양한 데이터의 videos featuring rapid dynamic motions을 포함

    → VGGT는 video tracking이라는 명시적으로 설계되지 않은 task에서도 탁월한 성능을 보여주며, VGGT로 추출되는 특징의 일반화 능력을 보여준다

Discussions

Limitations

  • 어안(fisheye), 파노라마(panoramic) 이미지 지원 안함
  • 입력 이미지에 대한 극심한 회전이 포함된 상황에서는 reconstruction 성능이 저하됨
  • minor non-rigid motions이 존재하는 장면 처리 가능

    → 하지만 큰 non-rigid deformation이 발생하는 장면에서는 실패

Advantages

그러나 VGGT의 중요한 장점은 유연성과 높은 적응성

위와 같은 한계들은 목적에 맞는 데이터셋으로 파인튜닝하는 것만으로도 비교적 쉽게 해결 가능함

이러한 적응성은, 특정 시나리오에 맞추기 위해 test-time optimization 과정에서 대규모 re-engineering이 필요한 기존 방법들과 차별화되는 특징임

Runtime and Memory

평가 요소

  • 추론 실행시간(runtime)
  • feature backbone에서 최대(peak) GPU 메모리 사용량

평가 환경

  • 하드웨어: NVIDIA H100 GPU

그 외

  • flash attention v3 사용
  • 이미지 해상도: 336 x 518

특히 feature backbone에서 발생하는 연산 비용에 집중하여 분석

→ 사용자가 필요한 출력(branch)을 각자의 요구되는 환경 및 자원에 따라 다르게 구성하기 때문

구조별 비용 특징

  • camera head
    • Runtime: 전체의 5% 차지
    • GPU memory: feature backbone 사용량의 2%만 사용
  • DPT head
    • Runtime: 평균적으로 0.03초
    • GPU memory: 프레임마다 0.2 GB

      → 또한 DPT heads는 프레임마다 독립적인 예측을 진행

Multi-frame inference

GPU 메모리가 충분하면 여러 프레임들을 single forward pass로 효율적으로 처리 가능

VGGT 구조에서는 프레임 간 관계(inter-frame relationship)가 feature backbone에서만 처리되고 DPT head는 프레임별 독립적인 예측을 수행

→ 따라서 GPU 자원이 제한된 경우 프레임 단위로 추론을 수행하는 것도 가능하며, 이와 같은 성능–자원 trade-off는 사용자의 선택에 맡김

Attention 연산 비용

naive한 global self-attention의 구현

→ 높은 메모리 부하, 대량의 토큰 발생

→ LLM 배포에서 사용되는 기술을 사용함으로써 절약 및 가속 가능

  • 예를들어 Fast3R은 다중 GPU에서의 추론 가속을 위해 Tensor Parallelism을 적용하며, 이는 VGGT에도 바로 적용가능

Patchifying

14 ×14 convolutional layer, 혹은 DINOv2를 이용하여 이미지를 패치화(patchifying)

→ DINOv2가 더 좋은 성능 및 학습 초기단계에서 훨씬 안정적인 학습을 보장

→ 또한 learning rate나 momentum과 같은 하이퍼파라미터의 변화에 덜 민감

→ 따라서 패치화에서는 DINOv2를 기본 모델로 선택

Differentiable BA

VGGSfM 에서와 같이 differentiable BA를 사용하는 아이디어도 탐색해봄

  • 소규모 예비(preliminary) 실험에서는 differentiable BA는 유망한 성능을 보임

    → 하지만 훈련 과정에서의 높은 연산 비용이 병목으로 작용

  • Pytorch 환경에서 Theseus를 이용해 differential BA를 구현한 경우, 각 training step이 4배 느려짐

    → 대규모 학습 환경에서 상당히 큰 비용

훈련 속도를 개선하기 위해 프레임워크를 직접 수정(customization)하는 것이 하나의 잠재적인 해결책이 될 수 있지만, 이는 본 연구의 범위를 벗어남

→ 하지만 differentiable BA는 명시적인 3D annotation이 부족한 상황에서 효과적인 supervision signal로 활용될 수 있기 때문에 향후 대규모 비지도 학습을 위한 유망한 방향이라고 봄

Single-view Reconstruction

DUSt3R, MASt3R

  • 이미지 쌍(pair)을 생성하기 위해 동일 이미지를 복제해야 하는 구조를 가짐

VGGT

  • 본질적으로 단일 이미지 입력을 지원

단일 이미지 입력

  • 이 경우 global attention은 자연스럽게 frame-wise attention 형태로 전환되어 동작

결과

  • 비록 VGGT가 단일 시점 reconstruction을 위해 명시적으로 학습된 모델은 아니지만, 실험 결과 놀라울 정도로 좋은 성능을 보여줌

Normalizing Prediction

본 연구에서는 GT(ground truth)를 정규화하여 학습을 진행

  • 3D 포인트들의 평균 유클리디언 거리(average Euclidean distance)를 기준으로 정규화 수행

DUSt3R와 같은 일부 방법들도 네트워크의 예측값에도 동일한 정규화를 적용

→ 하지만 본 연구의 실험 결과,

  • 이러한 정규화는 모델 수렴(convergence)에 필수적이지 않음
  • 최종 성능 향상에도 특별한 이점을 제공하지 않음
  • 예측값 정규화는 학습 과정에서 추가적인 불안정성을 유발하는 경향이 있었음

Conclusion

VGGT
  • 수백 개의 이미지 입력을 받아 3차원 장면의 여러 핵심 요소들을 직접 예측할 수 있는 feed-forward neural network
  • 여러 3D task 수행 가능
    • camera parameter estimation
    • multi view depth estimation
    • dense point cloud reconstruction
    • 3D point tracking
  • 기존 복잡한 최적화 기반 방법론들 대비 더 좋은 성능을 보임
