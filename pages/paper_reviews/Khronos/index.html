Abstract

우리는 이러한 문제를 제안해요

로봇이 동적 환경을 인지하는 것은 매우 중요하며, 동적(dynamic) SLAM 접근법들에서는 정확한 포즈를 추정할 수는 있지만, 주변 환경에 시공간(spatio-temporal) 표현 능력이 부족하다는 문제가 있다.

환경에 대한 시공간 표현이 왜 중요한데?

동적 환경에서 로봇의 장기간 자율화(autonomy) 및 추론(reasoning)에 사용되며, 또한 장/단기(long/short-term) 움직임(dynamics)에 대한 처리를 위해 사용된다.

우리는 이런 방식을 제안해요

따라서 본 논문에서는 Khronos라는 접근법을 제안하며, 이는 Spatial-temporal Metric Slam(SMS) 문제를 효율적으로 해결하는데, 구체적으로는 factor graph에서 active temporal window를 이용한 장/단기 움직임 처리하고, 이를 기반으로 dense한 시공간 지도(map)를 실시간으로 형성한다.

제안한 방식은 이렇게 평가해요
  • 시뮬레이션 환경
  • 실제 환경

Introduction

동적 환경에서 시공간의 개념은 중요해요

동적 환경에서 로봇이 안전하고, 효율적인 업무수행을 하기 위해서는, 과거 scene에 대한 정보를 기반으로 추론을 진행하여 지능적으로 행동하는 것이 요구된다.

기존 연구들은 이랬어요

Metric-semantic SLAM

  • Geometric Information

    → robot navigation, robot manipulation

  • Semantic Information

    → robot understanding, human understanding

    → 하지만 정적 환경에 제한되어 있음 (정적 환경에서 활용되는 로봇만 활용 가능)

Dynamic SLAM

  • 대부분 카메라 앞에서 움직이는 사람이나 객체를 다루는 short-term dynamics에 한정

    → 다른 연구들에서도, 현재 로봇이 보고 있지 않은 환경에서 객체가 갑자기 사라졌을 때, 이를 인지할 수 있는 long-term change detection을 연구하는 사례를 찾지 못했음

→ 로봇이 사람 곁에서 업무를 수행하기 위해서는 제한된 정보와 연산자원 내에서도 실시간으로 세상에 대한 이해를 할 수 있어야 함

따라서 이러한 해결책을 제안해요

논문의 핵심

  • spatio-temporal local consistency 기반 SMS 문제 해결

    → 센서 노이즈, 상태 추정 오차, 동적 객체, 장면의 장기 변화로부터 나오는 오류를 풀어냄

    = 시공간 인지 시스템 “Khronos”

평가

  • Dataset
    • 상세한 annotation이 붙은 가상의 scene들
  • Task
    • background reconstruction
    • object detection
    • motion tracking
    • change detection
  • Agent
    • 실제 동적 환경에서 주행하는 다중 로봇 플랫폼

SMS 문제의 목표

→ scene에 대한 실시간 시공간 이해

= 현재 시간 TTT﻿에 대해, 모든 이전 시간들 t≤Tt\le Tt≤T﻿ 에서의 scene의 상태 추정 문제

= 각 시간 TTT﻿에 대해, maximum-a-posteriori(MAP) 추정 문제

위 MAP 수식은 계산하기 어려우며, 이유는 아래와 같다.

  • 객체와 속성이 변하고, 알려지지 않은 변수가 많고, 비교적 적은 측정량 때문
  • 센서 노이즈, 불완전한 상태 추정, 움직이고 변하는 환경이 얽혀, 모든 변수들간의 강한 상호 의존성이 생김

    → 메모리에 모든 관측을 저장해야된다는 것을 의미

    → 연산량과 메모리 사용량이 증가

→ 센서 노이즈, 상태 추정 오차, 움직이는 객체, 변하는 환경 등이 현재 측정과 맵 신뢰도 간의 불일치를 초래할 수 있음

Local Estimation via an Active Window

(16)번 수식에서 Local Estimation 항을 active window라고 부르는데, (8), (9)번 수식의 local consistency를 만족시키는 관측 ZZZ﻿와 Φ\PhiΦ﻿로 구성된 fragments YkY_kYk​﻿의 집합을 점진적으로 추정함으로써, 해당 local 항을 푼다.

Reconstruction

수식을 만족하는 surface representation Ω\OmegaΩ﻿에 대해, khronos는 mesh를 이용해 정적 표면인 ΩBG\Omega_{BG}ΩBG​﻿를 모델링한다.

  • 매 RGB-D 프레임마다 후보 관측인 ZZZ﻿를 획득하여, ΩBG\Omega_{BG}ΩBG​﻿ 추정을 위한 projective TSDF fusion을 수행
    • 센서 데이터에서 ZZZ﻿를 획득하는 다른 단서(cue)들 존재
      1. 입력 프레임에서 제공되는 semantic mask 이용

Spatio-temporal Map Beliefs

아래 그래프는 office scene에서 Khronos의 change detection recall을 측정한 것이다.

구성

  • 로봇 시간 TTT﻿
  • 로봇 시간 TTT﻿ 까지의 정보가 주어졌을 때, 시간 t<Tt<Tt<T﻿에서의 world에 대한 belief

    → belief time과 robot time가 같은 (t=Tt=Tt=T﻿) 구간은 실시간 축을 의미

그래프를 보면 90초 쯤에 첫 변화가 탐지되고 몇 초동안은 해당 물체를 다시 감지하지 못한다.

이후에 변화가 탐지되어 recall이 증가하고, 새로운 물체가 등장하고 사라지면서 recall이 감소한다.

마지막쯤에 Loop가 닫히면서 시작 위치에서의 변화가 탐지되는데, 해당 정보를 기반으로 robot belief를 업데이트 한다.

→ 220초쯤에 로봇의 추정이나, 165초쯤에 belief time을 고정했을 때 결과(초록색 그래프)를 기반으로 성능의 향상을 알 수 있음

⇒ 해석 가능한 4D-metric을 제공

Computation Time

로봇이 제한된 연산 자원으로 scene에 대한 실시간 인지를 가능하게 하는 것은 중요함

Khronos

→ (16)번 수식 덕분에, 대략적인 상수 시간 복잡도로 동작 가능

active window 내부 프레임 처리 시간: 45.5 ±9.2ms

프레임율: 22.2 FPS

위 2개의 그래프는 제안하는 파이프라인의 runtime을 보여준다.

위쪽 그래프는 global optimization 요소들의 runtime 결과를 보여주며, 특히 optimization 과정에서 큰 runtime을 보이는 것을 확인할 수 있다. 이는 loop closure가 발생할 때만 관련이 있지만, 그래도 수초간의 runtime을 필요로 한다.

→ 하지만 이러한 연산은 각 분리된 thread에서 진행되며, 또한 매 프레임마다 계산할 필요가 없다

(따라서 크게 걱정할 필요는 없음)

또한 아래쪽 그래프는 reconciliation 요소들의 runtime 결과(worst case)를 보여주며, 특히 ray-hash의 recomputation이 큰 runtime을 보여준다.

→ 하지만 이 또한 ray-hash를 점진적으로 할당할 수 있고(한 번에 할당 안해도 됌), 대규모 loop closure 이후에 발생한다

(비슷하게 크게 걱정할 필요는 없음)

⇒ 모바일 로봇에서 실시간으로 시공간 지도 구축 가능

Limitations

Khronos

  • association edges를 구성할 때, fragment의 위치를 bounding-box centroid로 설정

    → 부분 관측이나 가려짐에 민감

  • fragment 사이의 6D 정합(registration) 부족

    → global estimation, reconciliation의 효과 감소

  • 만약 modern object pose, shape estimation, registration technique 적용?

    → fragment association의 강건성과 정확성이 더 올라갔을 것

Geometric Association

  • 만약 fragment descriptors 통합?

    → 움직이는 물체의 history에 대한 추론(reasoning) 가능

    → 동적 객체를 더 잘 처리할 수 있었을 것임

Surface of Change Detection

  • 변화 탐지에서 ray-tracing 접근법을 사용

    → reference surface에 의존

Memory

  • 모든 object fragment들을 메모리에 저장

    → 최적화 유연성은 증가하지만, Khronos의 확장성을 제한함

  • 이상적인 해결책

    → 너무 오래되었거나 충분히 신뢰있게 통합된 object fragments를 별도로 유지하지 말고, 전체 객체에 통합(marginalize)하기

    → 이를 통해 저장되는 객체 조각의 수는 실제 객체 수에 비례하게 되어, 장기간 매핑 임무를 효율적으로 수행 가능

느낀점

실시간으로 시공간 지도를 형성하면서, 동시에 일어나는 변화를 탐지하는 매력적인 논문이었다고 생각한다.

다만 변화 탐지가 기하학적인 변화에만 한정되어 있는 것 같아 아쉬웠고, 가만히 서있는 사람을 동적 객체로 인지할지 정적 객체로 인지할지 궁금했다.

향후 계획

특정 scene에서 시공간 정보를 이용해서 지금까지 일어나는 변화 정보를 기반으로 향후 일어날 위험을 감지하거나, human tracking에서 occlusion이 일어났을 때 진행방향과 시간정보를 통해 확률적으로 사람이 있을만한 위치를 예측하는 연구가 있는지 찾아볼 예정이다.
